# 추가 기능 목록

변경 범위가 큰 것으로 예상되는 기능엔 (MAJOR), 사소할 것으로 예상되는 기능에는 (MINOR) 태그를 앞에 붙임.

1. (MINOR) 상영 시간에 시작 시간 ~ 종료 시간 형태로 표기 (완료)
2. (MAJOR) 영화 목록 조회 시 포스터(이미지 파일)도 같이 보이기
3. (MINOR) 내 예매 내역 취소 기능 (완료)
4. (MAJOR) 상영 시간 선택 화면에서 잔여석/좌석 형태로 표기 (완료)

## 기능 구현 원칙
각 기능 구현 시마다 다음 원칙을 따른다.

1. 요구사항과 범위를 정리한다.
2. 기술 스택과 핵심 설계 결정을 내린다.
3. 프로젝트 실행 환경과 마이그레이션을 구성한다.
4. 요청 기능을 구현한다.
5. 필요 시 샘플 데이터를 추가한다.
6. 구현한 기능의 테스트를 작성하고 실행한다.
7. 필요 시 `README.md`를 수정한다.
8. 깨끗한 환경에서 실행 절차를 최종 검증한다.

각 단계가 끝날 때마다 빌드, 타입 검사, 린트, 테스트 중 프로젝트에 적용된 검증 명령을 실행하고 문제를 해결하라.

## 최종 보고 형식

구현을 마친 뒤 다음 순서로 결과를 요약하라.

1. 구현한 기능
2. 선택한 기술 스택과 이유
3. 핵심 설계 결정
4. 실행한 검증 명령과 결과
5. 남아 있는 제한 사항 또는 개선 가능 사항
